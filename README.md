# 这也算马？ / Doodle Derby

参考用户提供的 23 秒画马赛跑视频，在原型基础上实现的中文轻量游戏。原视频文件只作为视觉和玩法参考，没有作为网页资源上传。

## 本地运行

```sh
python3 -m http.server 5173
```

访问 http://localhost:5173 。无构建步骤、无第三方依赖。

## 已实现

- 支持鼠标、触控笔和手指的画板，四种颜色、撤销、清空、领养、随机名字。
- 画稿以归一化坐标和原画布宽高比保存，在画室、赛道、海报和挑战链接中保持等比例；画稿、名字与最佳成绩存储在本机。
- 100 米短跑：每 0.8 秒一个节拍，光标处于 72%–96% 区间时点击命中；每拍最多一次输入，连续命中加强冲刺。无需输入也能完赛。
- 涂鸦下部动态摆动，跟随赛道镜头，实时排名、计时和战绩海报；海报改成适合信息流转发的高对比分享卡，二维码缩到右下角，扫码直达当前局的好友挑战链接。
- 每日赛按 UTC 日期生成固定对手和每日规则；7 种规则轮换改变绿区、连击推力、对手速度、泥地速度、妖风和视觉提示。自由赛随机种子。
- 好友链接包含版本、手绘马、名称、赛道种子与成绩；海报二维码使用更短的抽样挑战载荷，方便手机识别，对手是按完赛成绩匀速移动的配速影子，并非真人联机或完整动作回放。
- 画稿分享时限量采样，解析时校验颜色、坐标、时间和大小；分享内容通过 textContent 显示。
- 标签页隐藏时暂停；返回画室取消动画循环；音乐在首次交互后开启，右上角可一键静音。
- 结算页的“这局有话说”可提交评分和文字反馈；首页没有反馈入口，手动打开 `/#feedbacks` 可查看和导出当前设备收集的反馈。
- 海报保存优先调用手机系统分享面板，iPhone/Android 可从面板选择“存储图像”进入相册；不支持系统分享时回退为 PNG 下载。
- 动态战绩优先生成浏览器原生 MP4；浏览器不支持 MP4 时生成轻量 GIF 动图，避免把无法在朋友圈使用的 WebM 作为唯一输出。

## 测试

```sh
node --check game.js
node --test tests/*.test.cjs
```

浏览器手动检查：桌面和 390px 手机布局、领养→比赛→结果、挑战链接打开、海报生成、返回画室。

## 发布与边界

将 `index.html`、`style.css`、`game.js`、`audio.js`、`adoption.js`、`results.js`、`qr.js`、`gif.js` 放到任何静态 HTTPS 托管即可。本地 localhost 链接无法给其他设备直接使用。当前线上地址为 https://horse.fde.fan/ 。

反馈收件箱使用浏览器 `localStorage`，因此 `/#feedbacks` 默认只显示提交反馈的这台设备内容；静态站点没有共享数据库。要做跨设备的集中收件箱，需要给部署增加可写的 KV、数据库或表单服务。

无账户、后端、真实多人匹配或全球排行榜；本机最佳不是全球排名。URL 中的成绩可被修改，不适用于奖金或严肃竞赛。挑战链接可能较长，正式推广可增加后端短链和服务端成绩校验。

传播验证建议：先用真实试玩观察画图完成率、首局完成率、再次开赛率、挑战分享率和好友打开后的开赛率。本版没有引入统计 SDK，也不对传播效果作保证。

## 音乐与音效

`audio.js` 是原创 MIDI 音符编排，用 Web Audio 实时合成复古音色，不需要下载音频或外部 MIDI 播放器。画室为轻柔循环，赛跑为 150 BPM 主旋律、低音及马蹄鼓；每个 0.8 秒操作周期中心绿区有提示铃。倒数、起跑、命中、三连击、失误和结算有独立音效。音乐跟随游戏时间，后台暂停、静音及切换场景会清理已排队音符。

旧版本机画稿未记录宽高比，首次加载新版时按当前画布比例补录；旧挑战链接缺少原比例，保持兼容，新链接会携带比例。

## 怪马领养池

12 款原创涂鸦：香蕉、轮子、弹簧、超长、职场、飞碟、鸭子、长颈、拖鞋、幽灵、拉面和火箭。每轮随机不重复，拥有专属名称和介绍，可继续编辑并参赛。当前会话中可还原领养前画稿。开发时可打开 `tests/adoption-gallery.html` 检查全部造型。

## 个性战绩

`results.js` 按角色、手绘轮廓、名字、名次、连击和挑战差值生成战绩。12 个领养角色拥有 48 条名次专属标题，另有 5 类手绘风格。页面和海报共用同一局文案，海报附专属单据名、计时标签、挑战语及战绩编号。编号用于趣味辨识，不是全球唯一身份。真实成绩保留，未声称百分位或虚构对手战绩。
